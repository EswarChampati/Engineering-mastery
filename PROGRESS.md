## Day 0 checklist

### Environment
- [ ] `node --version`
- [ ] `npm --version`
- [ ] `git --version`
- [ ] Confirm GitHub authentication and repository remote
- [ ] Configure Git author identity and verify it

### JavaScript
- [ ] Scope, hoisting, temporal dead zone, coercion
- [ ] Closures: counter, `once`, `memoize`
- [ ] Array/object transformations and immutable updates
- [ ] Promise ordering and event-loop prediction
- [ ] Bounded retry with exponential backoff

### TypeScript
- [ ] `ApiResponse<T>` and `Result<T, E>`
- [ ] Generic `getProperty` using `keyof`
- [ ] Generic repository
- [ ] Discriminated union and exhaustive check
- [ ] Explain `any`, `unknown`, `never`, narrowing, runtime validation

### Git/GitHub
- [ ] `status`, `add`, `diff`, `diff --staged`, `commit`, `log`
- [ ] Branch, switch, merge, and inspect graph
- [ ] Remote, push, upstream branch, pull request
- [ ] `.gitignore` and `git rm --cached`
- [ ] Practise restore/reset/revert in a disposable repository
- [ ] Practise stash and reflog recovery in a disposable repository
- [ ] Document what happened and what was recovered
