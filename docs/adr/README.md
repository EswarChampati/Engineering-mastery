# Architecture Decision Records (ADRs)

An ADR records one meaningful technical decision and why it was made. Keep each ADR short, specific, and immutable after acceptance; record a later change in a new ADR that supersedes the old one.

Suggested numbering:
- `0001-use-postgresql-for-primary-data.md`
- `0002-use-kafka-for-domain-events.md`

Use [`../../templates/adr.md`](../../templates/adr.md) as the starting template.
