# Architecture Documentation

Store diagrams and explanatory documents for integrated projects here.

For each architecture document, describe:
- Problem and requirements
- Main components and responsibilities
- Request/event/data flow
- Persistence and external dependencies
- Authentication, authorization, and trust boundaries
- Failure modes, observability, and recovery
- Important trade-offs and links to relevant ADRs

Suggested files:
- `system-context.md`
- `container-view.md`
- `deployment-view.md`

Diagrams can use Mermaid in Markdown when appropriate.
