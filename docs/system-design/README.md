# System Design Practice

Create one Markdown file per design exercise, such as `url-shortener.md` or `job-scheduler.md`.

Cover:
1. Functional and non-functional requirements
2. Capacity estimates and assumptions
3. API and data model
4. High-level architecture
5. Critical request/event flows
6. Bottlenecks, failure modes, and mitigations
7. Security and observability
8. Alternatives and trade-offs
9. Unanswered questions

State assumptions explicitly; do not present estimates as measured facts.
