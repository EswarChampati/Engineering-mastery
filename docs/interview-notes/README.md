# Interview Notes

Use this folder for concise, explainable answers—not copied textbook chapters.

For each topic, aim to record:
- A plain-language definition
- When and why it is useful
- A small example
- A trade-off or common failure mode
- Two likely follow-up questions

Suggested files: `javascript-async.md`, `typescript-generics.md`, `git-reset-vs-revert.md`, `postgresql-indexes.md`.
